# Changelog

The release workflow uses the section named after the version being released
as the release description, so every version needs one. `npm version <x.y.z>`
renames the `Unreleased` heading below to that version.

## 0.1.0

- First release: schedule the current note into a future daily note from a date typed in plain English, with quick picks, an optional note or the selected text, and a list of what is scheduled.
